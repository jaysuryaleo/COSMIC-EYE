# COSMIC EYE 🚀

**AI-Assisted Astronomical Observation Explorer**

COSMIC EYE is an interactive space observation platform designed to explore and compare real astronomical data from NASA's SPHEREx mission.

Our goal is to make astronomical observations easier to understand by allowing users to explore available images, view observation details, compare images of the same region, and generate difference visualizations.

## 🎯 Objectives

- Explore real NASA SPHEREx observations.
- Compare observations of the same region of space.
- Generate visualizations highlighting differences between observations.
- Support scientific investigation related to the Planet X challenge.
- Make astronomical data accessible through an interactive platform.

## 🔭 Scientific Note

COSMIC EYE is an exploratory tool. Image differences do not automatically indicate moving objects or confirm the existence of Planet X. All findings require scientific verification.
